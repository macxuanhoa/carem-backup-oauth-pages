# Privacy Policy — Carem Backup Rclone

**Last updated: October 24, 2026**

## Overview

Carem Backup Rclone is a private desktop backup utility used by an authorized operator to transfer encrypted backups of the Carem business management system to Google Drive.

## Google Drive Access

The utility uses the Google Drive API to upload, list, verify, download, and recover encrypted backup files.

The OAuth authorization may grant broad Google Drive permissions. The intended backup workflow operates within an operator-designated backup folder.

## Data Processing and Security

Backup data is encrypted locally before being uploaded to Google Drive. The utility processes file metadata, checksums, and backup contents as necessary for encryption, verification, and restoration.

OAuth credentials and encryption secrets are managed locally. Public GitHub Pages content does not contain backup data or credentials.

## Data Sharing and Retention

The utility does not sell personal information or use Google Drive data for advertising. Encrypted backups are stored in the authorized operator's Google Drive account and retained until removed by the operator.

## User Control

The operator can inspect or delete stored backups and revoke OAuth access through Google Account security settings.

## Google API Services User Data Policy

Use of information received from Google APIs is limited to providing the described backup and recovery functionality, consistent with the Google API Services User Data Policy, including its Limited Use requirements.

## Contact

For privacy-related questions, contact the application operator through the support email listed on the OAuth consent screen.
