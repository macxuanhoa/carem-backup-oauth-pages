# Carem Backup Rclone

**Secure, encrypted Google Drive backup for the Carem business management system.**

Carem Backup Rclone is a private backup utility used by an authorized operator to securely store and verify encrypted backups of the Carem system.

The application uses Google Drive API access to:

- Upload encrypted backup files to a designated Google Drive folder.
- List backup files and verify successful uploads.
- Download encrypted backup files for integrity checks and recovery testing.

Business records are backed up locally and encrypted before being uploaded to Google Drive. The application is intended for private administrative use, not public registration.
